## 資料與產品邊界

- 既有 localStorage 可能已混入舊版示範資料，無法可靠區分使用者修改與樣本；保留原資料，先匯出再人工整理，不自動刪除。
- 本機版本資料僅存在此瀏覽器；草稿也可能包含敏感內容。清除網站資料前先匯出備份；無跨裝置同步承諾。
- Obsidian 是手動 Markdown 匯出，非雙向同步。ZIP 目錄匯出可後續實作，不阻擋核心資料修復。
- 真實 Gemini 呼叫須有可用金鑰與目的地網路許可；模擬成功/失敗測試不等同遠端服務驗收。
- 不擴充 3D、圖表或架構展示；不修改 onboarding 產生的使用者 Vault 內容。

## 執行驗證

`npm test`：共用驗證、資料移轉/儲存故障、備份、API 契約與 AI 降級。

`npm run lint`、`npm run build`：型別檢查與正式打包。

瀏覽器驗收：使用獨立暫存 context，驗證空白啟動、保存重載、草稿切頁/日期、歷史導覽、備份覆蓋/取消/錯誤、可見 AI 備援與延遲回應隔離；不讀寫既有使用者瀏覽器資料。

## 第四輪：自動啟用（2026-11-01）

使用者要求取消人工啟用步驟。新增根目錄 `Start-LifeOS.cmd` 與 `deploy/windows/Activate.ps1`，串接使用者私有 Node/Bun 準備、鎖定依賴安裝、來源指紋快取、無人值守帳號初始化、受管理程序啟動、排程登記、就緒／匿名 API 驗證及恢復備份。Windows 登入觸發時由監督服務開啟前端；重複啟用以私有 PID/建立時間辨識自身程序，避免停止其他程序。

登入方式改為本機 OS 信任：私有 CLI 對受 ACL 保護的 DB 發出 60 秒、單次有效、DB 僅存雜湊的登入憑證，經瀏覽器 fragment 傳遞後立刻從網址移除。既有密碼與日誌不重設；未設定的本機帳號以強隨機憑證初始化，不要求人工輸入，也不捏造 Gemini 憑證。此流程僅能在明確啟用的 127.0.0.1 桌面模式使用，公開部署預設不提供兌換端點。密碼重設會撤銷既有登入及未兌換的桌面憑證。

已完成驗證：26 項 Node 資料／安全／自動化測試通過；個人瀏覽器 2 條端到端流程通過，新增的流程證明無密碼輸入自動登入、憑證移除及重放拒絕。PowerShell 語法、stdin/私有 CLI、來源指紋穩定與序列化程序身分辨識通過。Windows 工具下載/安裝、實際排程及 ACL 仍需實機驗收；系統執行政策或權限阻擋時會停止，不自動降級保護。
