# 策略閉環與自動演化

SSOT：策略、日期回報和演化決策均隸屬 PersonalOS.ifThenStrategies，隨原有工作區保存、同步與 JSON 備份流程處理。evolution.ts 是判定規則唯一來源。architecture.ts 是藍圖節點、層級、關係與循環步驟唯一來源；僅供程式與開發文件使用；一般介面改用簡單的使用說明。

MECE：輸入、建議、採納、保存、回報與評估分工；每個節點只屬一層。策略評估狀態互斥：觀察中／已驗證／自動暫停。手動啟用狀態與證據評估分開，已驗證不會強制啟用手動停用的策略。

每個策略每日期只有一份回報，可更正。最近三次已執行回報皆有效則驗證；皆無效則自動停用；未執行不列入樣本。更正或新增回報後即時重算，解除自動暫停時恢復原先啟用狀態。保留狀態變更時間與規則原因，不自動生成或修改行動文字，不推斷使用者沒有填寫的資料。離線無需模型金鑰即可運作。

舊資料沒有回報欄位時視為空回報；驗證器拒絕重複日期及非法結果。個人模式在保存後自動更新個人空間與 Obsidian 筆記；衝突時停止自動覆蓋。

驗證程序與目前限制統一見 [測試與驗收](TESTING.md)。策略演化的控制測試位於 tests/evolution.test.ts 與 tests/closed-loop-browser.mjs。
