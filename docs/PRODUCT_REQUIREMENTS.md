# 產品需求與範圍

本文件維護目前的產品範圍；各專題文件只維護自己的詳細規則。原始逐字稿與早期架設指令僅作歷史來源，不是現行執行指令。

## 從原始來源保留的核心需求

1. 每天先問「我今天過得好嗎？」；好時記錄原因與保持方法，不好時區分事實、情緒、原因與改善方法，普通時捕捉小小的順利或平靜。
2. 建議應具體、低負擔，盡量以「遇到什麼，就做一個小動作」呈現；尊重使用者，不將例子當成真實經驗。
3. 使用者選擇採納建議；個人手冊持續累積自己的策略、習慣提問、有效方法與注意事項。
4. 閉環包含記錄、建議、採納、保存、實踐回報及自動評估。詳細規則只在 CLOSED_LOOP.md 維護，自動演化為必要功能。
5. 介面面向不熟悉技術的使用者，保持極簡；技術藍圖、逐字稿、開發指令不出現在一般使用流程。

## 資料責任

Windows 個人模式由資料庫保存權威記錄，NotesRoot 中的筆記是可重建的輸出；瀏覽器模式的資料仍屬各自瀏覽器，不能聲稱兩種模式自動共用。不得把範例手冊或舊版模板自動匯入使用者工作區。

工具與資料目錄位於專案內，權限與網頁存取受限制且 Git 忽略。日記備份、原始參考文件、加密金鑰不發布。備份及資料保留規則由 Windows 操作文件解釋，實作以相應模組為準。
