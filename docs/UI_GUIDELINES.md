# 使用者介面原則

預設讀者不熟悉技術名詞。日常操作以今天、我的小改變、生活回顧、備份為主，其餘收進更多。

主要流程：選心情、寫幾句、儲存。主題與相關事情為選填，預設收合；額外提醒與經驗整理也預設收合。保留既有資料格式、備份覆蓋前保護與衝突處理。

自動調整仍依實際嘗試結果進行：連續三次無效先暫停，未嘗試不計；更正結果可重新判定。畫面用「這個方法有幫助嗎？」呈現，不要求理解演化引擎。

架構、模型版本、原始規格與逐字稿留在原始碼及文件，使用說明只談使用者任務。預設建議清楚標示非 AI 產生，避免誤導。

登入頁提供「開啟我的日記」按鈕，透過目前使用者的固定本機啟動連結啟動一次性登入。連結不得攜帶任意命令。第一次瀏覽器可能要求允許外部啟動；失敗時提供折疊式協助與既有密碼登入。一次性登入可在新頁或原頁收到，憑證立即從網址移除，重播被拒絕。

驗證包括四種視口 375 / 390 / 768 / 1440，主要頁無水平溢出，控制項至少 44px。測試涵蓋日記、草稿、備份還原、同步衝突、登入與策略回報保存。專案長期規則另見 AGENTS.md。
